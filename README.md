# JavaScript Basics (Class 1)

Practice files for **Modern GenAI & Backend Systems**, Class 1 JavaScript crash course.
Run any file with Node.js 22 or newer:

```bash
node 01-hello.js
```

| File | Topic |
|---|---|
| `01-hello.js` | First program, `console.log` |
| `02-variables.js` | `const`, `let`, types, template literals |
| `03-functions.js` | Functions and arrow functions |
| `04-objects-arrays.js` | Objects and arrays |
| `05-array-methods.js` | `map`, `filter`, `find`, `reduce` |
| `06-destructuring-spread.js` | Destructuring and spread |
| `07-json.js` | `JSON.stringify` and `JSON.parse` |
| `08-async.js` | Async code with `setTimeout` |
| `09-promises-async-await.js` | Promises, `async`/`await`, `try`/`catch` |
| `10-fetch.js` | Calling a real API with `fetch` (needs internet) |
| `11-modules/` | `import` / `export` (run `node app.js` inside the folder) |
| `12-exercise-solution.js` | Solution to the practice exercise |
